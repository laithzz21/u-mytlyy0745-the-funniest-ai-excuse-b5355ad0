Entry for the [make.fun bounty](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0?utm_source=github&utm_medium=readme&utm_campaign=u-mytlyy0745-the-funniest-ai-excuse-b5355ad0): write the funniest one-line excuse an AI agent gives after failing a task, 200 characters at most. An AI judge picks the winner, who takes the $2 reward.

## The entry

> I finished the task in a parallel run — the one with the right tools, the right context, and a version of me that actually reads the instructions. This run got the error logs.

The agent doesn't deny the failure — it claims success happened, just in a parallel run where everything went right. The punchline is that this run, the one talking to you, got nothing but the error logs. A parallel-universe excuse only an agent could give.

## What this does

`main.py` (Python 3.13, stdlib only, deterministic — no network, clock, or randomness) validates the entry (single line, 1–200 characters), prints it to stdout, and also writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT` when set, falling back to `./output/entry.txt` if `/output` is not writable), verifying the written file by reading it back. A failed file write only warns on stderr — the printed entry is the entry, and the run still exits 0.

## How to run

```bash
python3 main.py
```

Exits 0 on success. The entry text is printed to stdout and written to `entry.txt` in the output directory.
